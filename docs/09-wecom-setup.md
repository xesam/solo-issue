# 接入企业微信

> 从模拟通道切到真实企微的完整接入步骤：前置准备 → 建自建应用取凭证 → 应用内三处配置 → 免登/扫码双路径冒烟。
> 登录双入口 `/start`（客户端内静默免登）与 `/web-start`（PC 扫码）的设计与 Provider 实现见 [03-auth.md](03-auth.md)；本篇只讲运维侧接入。

## 1. 两种通道

| 通道 | 开关 | 用途 |
|---|---|---|
| **真实通道** | `WECOM_CORP_ID` / `WECOM_AGENT_ID` / `WECOM_SECRET` 三件套齐备 | 生产：凭证齐全自动切换，**零代码改动** |
| **模拟通道** | `ALLOW_IM_MOCK=1`（未显式设置时默认 `NODE_ENV !== "production"`） | 开发/演示：无需任何企微配置（行为边界见 [03-auth.md](03-auth.md) §7） |

本地与联调可用个人免费注册的测试企业（200 人内免费）+ 自建应用完成。

## 2. 前置准备（申请前先定）

| # | 事项 | 说明 |
|---|---|---|
| 1 | **部署域名** | 系统对外地址，**必须先定**——可信域名/回调都依赖它；需公网可访问（纯内网部署需提前规划"临时公网验证"或"公网入口回内网"方案） |
| 2 | **服务器出口 IP** | 部署机访问公网的出口 IP（固定出口/NAT），用于"企业可信 IP"配置 |
| 3 | 应用可见范围 | 全员或指定部门——决定谁能登录、能收到通知与应用可读取的成员资料 |
| 4 | 应用名称与图标 | 展示在企微工作台 |

## 3. 创建自建应用并取凭证

企微管理后台 `work.weixin.qq.com` → **应用管理 → 应用 → 自建 → 创建应用**（需超级管理员权限）：

- 创建时选择**可见范围**（§2 第 3 项），系统随后生成 **AgentId** 与 **Secret**
- 另需记录企业信息页的 **CorpID**（企业 ID）
- **Secret 等同密码**：安全渠道传递、不落聊天记录；泄露可在应用详情页随时重置（旧的立即失效）

## 4. 应用内三处配置（应用详情页 → 开发者接口）

| 配置 | 内容 | 作用 |
|---|---|---|
| 网页授权及 JS-SDK → **可信域名** | 填部署域名，下载 `WW_verify_xxx.txt` 完成归属验证。注意默认部署挂在部署前缀之下（如 `/solo-issue`），应用不响应域名裸根——验证文件须由反向代理在根目录返回（Nginx 配置示例见 [08-deployment.md](08-deployment.md) §4） | 企微客户端内打开 H5 静默免登（snsapi_base）；**也是 PC 浏览器扫码登录（wwlogin）的回调域名——零新增配置**。仅需网页授权能力，无需前端接入 JS-SDK |
| **企业可信 IP** | 添加部署机出口 IP | 服务端调企微 API（换 token/读成员/发消息）强制要求，未配置报错（错误码 60020） |
| **应用主页**（推荐） | 设为 `https://<域名><部署前缀>`（默认部署即 `https://<域名>/solo-issue`） | 企微工作台点图标直达 |

通讯录读取与消息推送用自建应用默认权限即可（最小权限原则，无需申请"通讯录同步"）。

## 5. 联调冒烟（双路径）

1. `.env` 填入 `WECOM_CORP_ID` / `WECOM_AGENT_ID` / `WECOM_SECRET` 三件套，移除 `ALLOW_IM_MOCK`
2. 重启应用（Docker：`docker compose --env-file apps/web/.env up -d`——compose 的 ${WECOM_*} 插值须显式指向 .env；裸机：重启 app 与 worker 进程）——代码零改动，凭证齐全即自动切真实适配器；确认 **worker 进程在跑**（textcard 通知经它发出）
3. **客户端内打开**：企微客户端工作台点开应用落在登录页，点「企业微信登录」按钮后 snsapi_base 静默授权完成登录
4. **PC 扫码登录**：系统浏览器走登录页「企业微信扫码登录」（wwlogin）——同一成员两种方式登录落同一账号；仅限本企业可见范围内成员，范围外成员无法扫码成功
5. 被指派一个 issue → 收到 textcard 通知，确认登录与通知全链路畅通

## 6. 企微排障

| 症状 | 排查 |
|---|---|
| 登录页没有企微入口 | 三件套未配且 `ALLOW_IM_MOCK` 未开（providers 接口 enabled=false 即正常未配置） |
| 企微回调跳登录页带 error | 核对回调域名配置、服务器出口 IP 是否在可信 IP 列表、Secret 是否正确 |
| 通知只有站内没有企微 | worker 进程日志 `[im-send]`（Docker：`docker compose logs worker`；裸机：worker 进程输出）；用户无企微身份（用邮箱直登建的号）会静默跳过 |

> 部署层通用排障（健康检查/附件/数据库/找回管理员密码）见 [08-deployment.md](08-deployment.md) §10。
